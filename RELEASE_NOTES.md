Version 3.5.6 is a text change only.

The three model options that carry a qualifier used an em dash to separate it
from the name. At menu-item size that reads as part of the name rather than as
punctuation, so it is now an arrow:

- Accurate → recommended
- Unified → most accurate
- Transcribe → slowest

Nothing else changed from 3.5.5.

The app is signed with a stable Apple Development identity and is not
notarized, so the first launch still needs one approval through System
Settings > Privacy & Security > Open Anyway. Audio and transcripts remain
local, and every bundled Whisper model is verified against a pinned SHA-256.
