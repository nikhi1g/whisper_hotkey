# whisper_hotkey 3.2.0: Hardware-Aware First Run

Version 3.2.0 gives a clean installation responsive defaults without replacing
settings during an update.

## Highlights

- Use Right Option as the clean-install dictation key.
- Choose only verified models already available on the Mac.
- Prefer Base below 8 GB, Small at 8 GB or more, and Large-v3 Turbo Q5 at
  16 GB or more, falling back to the next available lower tier.
- Use Metal with Precision decoding.
- Use Decode While Speaking at 8 GB or more and After Recording below 8 GB.
- Preserve every existing preference.

The downloadable DMG still includes the pinned Base English model and performs
no runtime model download.

See [Fresh Install Test](../FRESH_INSTALL_TEST.md) for the isolated end-to-end
download checklist.
