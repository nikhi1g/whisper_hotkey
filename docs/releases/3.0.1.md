# whisper_hotkey 3.0.1: Interface Polish

Version 3.0.1 corrects the Settings summary layout and shortens empty-recording
feedback.

## Highlights

- Wrap summary chips across two stable rows inside the Settings window.
- Preserve complete labels for long recognition configurations.
- Keep the User Guide button fixed at the right side of the footer.
- Dismiss No Speech Detected after 200 milliseconds.
- Preserve all other error and cancellation durations.

Quick Start:

```sh
git clone https://github.com/nikhi1g/whisper_hotkey.git
cd whisper_hotkey
./run.sh
```

The release includes source and a signed Apple Silicon app bundle. It is not
notarized, and model weights remain separate from the application archive.
