# whisper_hotkey 3.0.6: Completion Tail

Version 3.0.6 protects the final spoken word when Send or Enter overlaps active
speech without delaying completion after silence.

Recommended for all users of version 3.0.

## Highlights

- Keep capturing for a bounded 240 milliseconds only when confirmed speech is
  still recent at Send or Enter.
- Finalize immediately when the recording is silent, unknown, or already has
  at least 180 milliseconds of trailing silence.
- Preserve the exact Send/Enter-time destination while the audio tail finishes.
- Cancel pending post-roll safely on cancellation, replacement, or shutdown.

Quick Start:

```sh
git clone https://github.com/nikhi1g/whisper_hotkey.git
cd whisper_hotkey
./run.sh
```

The release includes source and a signed Apple Silicon app bundle. It is not
notarized, and model weights remain separate from the application archive.
