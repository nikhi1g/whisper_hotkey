# whisper_hotkey 3.0.5: Settings Continuity

Version 3.0.5 integrates custom-theme editing directly into Settings and
restores standard macOS window behavior.

Recommended for all users of version 3.0.

## Highlights

- Expand custom-theme controls inline instead of opening a separate sheet.
- Grow and collapse the Settings window around the editor, with vertical
  scrolling whenever the complete document exceeds the display.
- Show the runtime HUD's top-center waiting marker in the live theme preview.
- Support Command-W, Command-M, Control-Command-F, and the standard macOS
  close, minimize, resize, and full-screen controls.
- Remove the redundant User Guide subtitle.

Quick Start:

```sh
git clone https://github.com/nikhi1g/whisper_hotkey.git
cd whisper_hotkey
./run.sh
```

The release includes source and a signed Apple Silicon app bundle. It is not
notarized, and model weights remain separate from the application archive.
