# whisper_hotkey 3.1.0: Controllable Transcript Retention

Version 3.1.0 adds a persistent Settings control for Copy Last Dictation and
makes the notarized DMG the primary installation path.

## Highlights

- Keep only the latest successful transcript in memory by default.
- Turn retention off at any time to clear it immediately and hide the menu item.
- Preserve Pause Mode's private bounded session context independently.
- Download the stable, signed, notarized DMG without using Terminal.
- Use direct behavior chips and a clearer key selector in the product demo.

The app remains English-only, local, and designed for Apple Silicon Macs running
macOS 14 or newer.
