# whisper_hotkey 3.1.1: Update Checks

Version 3.1.1 adds a manual stable-release check and an off-by-default automatic
check that runs once per launch when enabled.

## Highlights

- See update availability directly in Settings.
- Persist the automatic-check preference across launches.
- Request only public GitHub stable-release metadata.
- Keep automatic downloads and installation disabled.
- Preserve local-only audio, transcription, dictionary, and settings data.

This is a source-only test patch for validating the update notification path.
