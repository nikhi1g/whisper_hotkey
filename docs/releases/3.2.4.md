# whisper_hotkey 3.2.4: Clean Dictation and a Real Install

Version 3.2.4 removes internal dictionary entries from transcripts and turns
the ZIP download into a proper installation.

## Internal dictionary no longer echoes into transcripts

whisper treats an initial prompt as prior transcript text. Given a clip with no
real speech, the decoder could "continue" the vocabulary hint instead of
transcribing, emitting entries verbatim. With Decode While Speaking, the pauses
between phrases are decoded as their own clips, so those entries appeared in
the middle of otherwise correct dictation.

The existing quality gates never caught it, because the hallucinated text
decodes with high confidence and a low no-speech probability. The vocabulary
hint is now withheld from any clip whose signal falls below a normalized RMS
floor, where there is no speech for it to help recognize anyway. Genuinely
spoken dictionary words are still recognized.

## The download installs itself

- On first launch from outside Applications, the app offers to move itself
  there, then relaunches from the installed copy. A quarantined download
  otherwise runs from a read-only App Translocation mount, which cannot be
  updated in place.
- Quarantine is cleared on the installed copy, because reaching the prompt
  already required approving that exact build.
- Settings opens once on a new installation.

## Models

- Base English, Small English, and Large-v3 Turbo Q5 ship inside the app. That
  is every model the first-run profile can select on its own, so no Mac starts
  on a model it does not have. The download is about 1 GB.
- Medium English is fetched on demand with a progress bar and pinned SHA-256
  verification. Selecting it previously did nothing at all. All four models
  together exceed the 2 GB release-asset limit, so it cannot be bundled.

## Updates

Downloading, verifying, and installing an update now reports progress and can
be cancelled.

## Signing status

Unchanged: signed with a stable Apple Development identity, not notarized, so
`spctl --assess` reports `rejected` and the first launch needs one approval
through System Settings > Privacy & Security > Open Anyway.
