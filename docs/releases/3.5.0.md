# whisper_hotkey 3.5.0: Two New Engines

This release is the result of a survey of every open speech model that ranked
above the shipping engine on the Open ASR Leaderboard. Two of them made it in.
Both are additions: nothing existing changed.

## The survey

Eight candidates ranked above Parakeet TDT 0.6B v2's 6.05 average word error
rate. Applying license, architecture, Apple Silicon availability, and a
measured comparison against this repository's own corpus:

| Model | Leaderboard WER | Outcome |
| --- | ---: | --- |
| ARK-ASR-3B | 4.76 | No Core ML path; would need a converter we would own |
| MOSS-Transcribe-preview-2B | 4.87 | No Core ML path |
| Cohere Transcribe 03-2026 | 5.42 | **Added** — see below |
| ARK-ASR-0.6B | 5.53 | No Core ML path |
| Zipformer-cr-ctc-XL-290M | 5.56 | CC-BY-NC, incompatible with an MIT app |
| Qwen3-ASR-1.7B | 5.76 | No Core ML path |
| Phi-4-multimodal | 6.02 | Not meaningfully better than 6.05 |
| Audio8-ASR-0.1B | 7.03 | CC-BY-NC, and worse than both shipping tiers |

The recurring lesson is that leaderboard rank did not predict behavior on this
corpus. Two models that ranked comfortably ahead lost once measured here.

## Parakeet Unified

The only candidate that beat the shipping engine on this project's own
benchmark. Measured over the same 100 LibriSpeech utterances, Apple M5 Pro,
both warmed up:

| Model | Combined WER | test-clean | test-other | Mean | Median | p95 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Parakeet Unified | **2.46%** | **1.44%** | **3.63%** | **50 ms** | **41 ms** | 105 ms |
| Parakeet Accurate | 2.62% | 1.54% | 3.86% | 56 ms | 53 ms | **78 ms** |

It wins every accuracy figure and both mean and median latency — a strict win,
which none of the other candidates managed.

Its one regression is the tail. Audio longer than 15 seconds is transcribed
with overlapping windows, and all seven such files in this set are slower than
Accurate: 138 ms against 100 ms at the worst. Dictation phrases are seconds,
not tens of seconds, so the median governs what a user feels and the worst case
stays bounded.

It is a third variant rather than a replacement. Fast and Accurate are
untouched, the presets still resolve to them, and no saved selection changes.
It is downloaded on demand at 594 MB; bundling it as well would take the
release asset close enough to GitHub's 2 GB ceiling to be reckless.

Unified also carries streaming encoders at 320 ms through 2080 ms latency
tiers, which this release does not use. Decode While Speaking still re-decodes
chunks. That is the obvious next step.

## Cohere Transcribe

The highest-ranked permissively licensed model with an existing Apple Silicon
path: Apache-2.0, fourth overall, and already carrying a Core ML build and a
pipeline in the FluidAudio dependency. On this corpus its ranking did not hold:

| Engine | Combined WER | test-clean | test-other | Mean latency |
| --- | ---: | ---: | ---: | ---: |
| Cohere Transcribe | 2.57% | **1.13%** | 4.21% | 629 ms |
| Parakeet Accurate | 2.62% | 1.54% | **3.86%** | **56 ms** |

The 0.63 point lead it holds on the leaderboard's seven-split mean becomes a
0.05 point tie here. It is clearly better on clean read speech — a 27% relative
improvement — clearly worse on noisy speech, and eleven times slower, because
it is a 2B encoder-decoder that emits one token at a time.

It ships as a fifth engine, Advanced only, never resolved to by a preset,
downloaded on demand at 2.4 GB. The confirmation dialog states the measured
latency and the clean-versus-noisy split before the download rather than after.

## Method

The benchmark harness now measures Parakeet TDT, Parakeet Unified, and Cohere
through the same tokenizer and edit distance as the Whisper benchmark, so any
future claim can be checked against this corpus before it is believed. Two of
the models in this release are cases where that check changed the answer.

## Compatibility

Every engine, model, preset, and decoding profile from 3.4.2 behaves
identically. No preference is migrated or rewritten.
