# whisper_hotkey 4.2.9

Released: 2026-09-12

## Selectable microphone routing

- Offer a Microphone submenu in the menu bar with Automatic plus every available Core Audio input.
- Persist manual choices by stable device UID and configure only whisper_hotkey's owned audio engine.
- Reapply the selected device after route recovery without changing the macOS system default.
- Fail visibly when a manually selected device is unavailable rather than silently capturing another source.
- Report both configured and effective active microphones through terminal status.

## Faster Model Ready response

- Keep the complete-session recognition path and remove duplicate per-session model preparation.
- Wake the warm whisper.cpp helper when a response arrives instead of polling every 10 ms.
- Preserve full audio context, dictionary prompt, decoding strategy, beam width, sanitization, formatting, and exactly-once delivery.
- Leave Parakeet decoding unchanged.

## Capture reliability

- Recover once when an audio engine is running but produces no non-empty first buffer within one second.
- Scope watchdog recovery to the active capture token.
- Fail visibly and perform normal private-audio cleanup if starvation continues.

## Verification contract

- The complete Swift suite, bootstrap and release-tooling suite, signed bundle, installed runtime, and built/installed hashes must pass.
- Menu and Settings tests cover Automatic, manual, disconnected, and busy-state microphone behavior.
- Capture tests cover token-scoped first-buffer and route recovery.
- A physical external-microphone dictation remains the decisive hardware-routing check.

## Distribution

Stable publication uses one Developer ID-signed, hardened, securely timestamped, notarized, and stapled `whisper_hotkey.dmg`. Gatekeeper assessment is mandatory. The website, GitHub release, and in-app updater use that DMG and its matching SHA-256 asset; no packaged application ZIP or unnotarized fallback is published. The application remains native arm64 for macOS 14 and later.
