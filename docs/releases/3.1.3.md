# whisper_hotkey 3.1.3: Update Verification Fix

Version 3.1.3 fixes the explicit verified update installation path in Settings.

## Highlights

- Parse the designated signing requirement from either `codesign` output
  stream.
- Preserve the `.app` extension on the launcher's private incoming bundle.
- Avoid an unnecessary Gatekeeper fallback when the installed and incoming apps
  have the same signing requirement.
- Preserve the full checksum, bundle, version, and signature validation path.
- Report installation failures as **Update failed**.

Automatic checks remain off by default. Automatic installation is not enabled.
