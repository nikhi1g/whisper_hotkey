# whisper_hotkey 3.0.0: Parallel Recognition

Version 3.0 introduces an optional recognition pipeline that works while the
user is still speaking.

## Highlights

- Choose After Recording, Model Ready, or Decode While Speaking.
- Run bounded background chunk decoding through one serial local model runtime.
- Keep intermediate text private and perform one final insertion.
- Retain the uninterrupted session recording for safe full-context fallback.
- Use confidence-adaptive Smart Decode to reserve beam search for uncertain
  speech.
- Reproduce latency and accuracy measurements with the included LibriSpeech
  benchmark.

Quick Start:

```sh
git clone https://github.com/nikhi1g/whisper_hotkey.git
cd whisper_hotkey
./run.sh
```

The release includes source and a signed Apple Silicon app bundle. It is not
notarized, and model weights remain separate from the application archive.
