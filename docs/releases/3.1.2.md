# whisper_hotkey 3.1.2: Update and Restart

Version 3.1.2 adds an explicit verified update installation path to Settings.

## Highlights

- Turn an installable available release into an **Update and Restart** action.
- Verify the DMG checksum before mounting it.
- Verify the incoming app's version, bundle ID, signature, and trust identity.
- Replace the installed bundle with rollback protection after the app exits.
- Relaunch automatically and clean all temporary update files.

Automatic checks remain off by default. Automatic installation is not enabled.
