# whisper_hotkey 3.0.8: Downloadable Mac App

Version 3.0.8 adds a conventional, self-contained Mac download while preserving
the source bootstrap and the app's private, on-demand runtime.

## Highlights

- Publish a Developer ID-signed and Apple-notarized DMG through GitHub Releases.
- Bundle the pinned, verified Base English model for immediate local dictation.
- Add a dedicated product page with direct download and source links.
- Preserve the verified `git clone` → `./run.sh` installation path.
- Keep runtime recognition offline, recordings ephemeral, and idle use minimal.

The release is for Apple Silicon Macs running macOS 14 or newer. Open the DMG,
drag whisper_hotkey into Applications, open it, and complete the three macOS
permissions shown by Setup.
