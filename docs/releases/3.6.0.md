Version 3.6.0 cuts the recognition list from ten options to five, stops
hiding the controls behind those options, and fixes a model list whose
category headings behaved like models.

## Five options, not ten

Four of the ten entries could not run on any shipped install:

- **Turbo and Base on the Core ML encoder** were gated behind a marker file
  the release bundle never contained, so both failed unconditionally.
- **Turbo and Base on WhisperKit** needed a compiled model directory that
  nothing shipped and nothing downloaded.

A fifth, **Whisper Base on Metal**, lost its case once Parakeet Fast was
bundled: Fast is 76 MB smaller, faster, and more accurate, and Base's prompt
conditioning is equally available on Turbo.

The argument that once justified three Whisper backends — that Metal covers
older Macs — no longer holds. The shipped binaries are arm64-only, so every
user has a Neural Engine.

What remains is what a user can actually select and run:

| Family | Options |
| --- | --- |
| Parakeet | Accurate (bundled) · Fast (bundled) · Unified (594 MB) |
| Whisper | Turbo (bundled) |
| Cohere | Transcribe (2.4 GB) |

A saved preference naming a retired engine resolves to Metal, which runs the
same weights. A saved Base selection reads as Turbo. Nothing is rewritten
silently and no dictation behavior changes.

## The settings you are using are the settings you can see

Model, Decoding, and Processing sat behind an "Advanced Options" disclosure
that defaulted to closed. That hid the only explanation for what a preset had
selected, and the fold could not even stay folded: it forced itself open and
relabelled itself "(in use)" whenever the configuration read as Custom.

All three rows are now permanent. Decoding still hides when the selected
engine has no beam search, which is a different rule — that row would
otherwise report a value it does not control.

## Headings that are headings

Parakeet, Whisper, and Cohere name families, not models, but they highlighted
on hover and accepted a click that did nothing. The headings were marked
disabled; `NSMenu` discarded the flag, because it re-derives each item's state
from its target and action unless told not to.

They are now genuinely unselectable, upper-cased and dimmed to match the
section titles above them, with their members indented one level. The same
latent bug affected the theme list's Dark, Light, and Custom headings and is
fixed there too.

## Smaller

Removing the two engines removed the WhisperKit Swift package dependency, its
in-process runtime, the Core ML encoder download-and-build path in `run.sh`
(including a pinned whisper.cpp source clone and CMake build), and the
WhisperKit model download script.

## Compatibility

Every remaining engine, model, preset, and decoding profile behaves exactly as
it did in 3.5.6.

The app is signed with a stable Apple Development identity and is not
notarized, so the first launch still needs one approval through System
Settings > Privacy & Security > Open Anyway. Audio and transcripts remain
local, and every bundled Whisper model is verified against a pinned SHA-256.
