# whisper_hotkey 3.1.4: Faster Hotkey Response

Version 3.1.4 prioritizes microphone capture immediately after hotkey
activation.

## Highlights

- Start audio capture before resolving the badge's exact caret anchor.
- Show the listening badge only after its correct position is available.
- Schedule model preload work after recording has started.
- Remove redundant explanatory copy from Settings.

Audio and transcript privacy behavior is unchanged.
