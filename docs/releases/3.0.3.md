# whisper_hotkey 3.0.3: Transcription Continuity

Version 3.0.3 keeps the complete listening HUD visible while local
transcription finishes.

Recommended for all users of version 3.0.

## Highlights

- Preserve the final waveform, elapsed time, Stop, and Send controls during
  transcription instead of showing an empty capsule.
- Overlay the existing perimeter activity trail on the frozen listening HUD.
- Show its exact top-center starting point as a small waiting marker while
  listening, then remove the marker when the trail begins.
- Keep the transcribing panel non-interactive and remove it as soon as local
  transcription and insertion complete.

Quick Start:

```sh
git clone https://github.com/nikhi1g/whisper_hotkey.git
cd whisper_hotkey
./run.sh
```

The release includes source and a signed Apple Silicon app bundle. It is not
notarized, and model weights remain separate from the application archive.
