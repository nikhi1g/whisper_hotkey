# whisper_hotkey 3.2.3: Installable Download

Version 3.2.3 fixes the public download. Earlier assets could not be opened at
all: the disk image was signed with a development certificate and was never
notarized, so macOS 15 and later blocked it before it could mount and offered
only **Move to Trash**.

## Highlights

- Download `whisper_hotkey.zip`. macOS applies quarantine to the
  extracted app rather than blocking a disk image, so the first launch can be
  approved through **System Settings → Privacy & Security → Open Anyway**.
- The README and the product page document that one-time approval, including the
  fact that right-click → Open no longer bypasses Gatekeeper on macOS 15 and
  later.
- Both assets ship a `.sha256` file so the download can be verified before it is
  approved.
- The release workflow builds and publishes the assets again. It previously
  failed immediately on missing notarization secrets, which is how an
  unopenable, hand-uploaded disk image reached the release page.
- `tools/package_dmg.py` now requires an explicit channel and refuses to publish
  an ad-hoc or preview build under the public release name.

## Signing status

The app is signed with a stable Apple Development identity and is **not
notarized**; notarization requires a paid Apple Developer Program membership.
`spctl --assess` reports `rejected` for these artifacts, which is expected.
Keeping the identity stable preserves in-app updates and existing Microphone,
Accessibility, and Input Monitoring grants.

The `whisper_hotkey.dmg` asset is unchanged in name and purpose: the in-app
updater downloads and mounts it directly, where quarantine never applies.

Audio and transcripts remain local, and the bundled Base English model is still
pinned and SHA-256 verified.
