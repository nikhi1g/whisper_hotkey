# whisper_hotkey 3.0.7: Instant Start

Version 3.0.7 makes accepted dictation startup visibly immediate while retaining
the existing private, on-demand microphone lifecycle.

Recommended for all users of version 3.0.

## Highlights

- Present and synchronously draw the listening HUD before microphone hardware
  initialization can block the main event path.
- Remove the consistent half-second-looking dead period after an accepted
  toggle or hold start.
- Keep the microphone and audio worker fully off at idle.
- Preserve modifier shortcuts, hold dwell semantics, and local-only capture.

Quick Start:

```sh
git clone https://github.com/nikhi1g/whisper_hotkey.git
cd whisper_hotkey
./run.sh
```

The release includes source and a signed Apple Silicon app bundle. It is not
notarized, and model weights remain separate from the application archive.
